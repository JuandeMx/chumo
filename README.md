# 🔥 PANEL CHUMO - Instalador Oficial sin Keys / Licencias 🇲🇽

Panel de administración y gestión de servidores VPS Linux (Ubuntu / Debian), derivado y limpiado para funcionar **totalmente libre sin llaves, licencias ni dependencia de bots externos de verificación**.

---

## 🚀 Instalación en Una Línea (Cualquier VPS)

Copia y pega este comando en la terminal de tu VPS como usuario `root`:

```bash
apt-get update -y && apt-get install -y git && rm -rf /tmp/chumo && git clone https://github.com/JuandeMx/chumo.git /tmp/chumo && cd /tmp/chumo && chmod +x install.sh && bash install.sh
```

---

## 💻 Comandos de Acceso al Panel

Una vez instalado, ingresa a la consola en cualquier momento escribiendo cualquiera de estos comandos:

👉 `chumo`  o  `menu`  o  `adm`

---

## 💎 Características e Instaladores Incluidos

- **Control de Usuarios:** SSH, SSL/TLS, Dropbear, VMess, V2Ray, Shadowsocks-R.
- **Proxies Python:** `PDirect.py`, `PGet.py`, `POpen.py`, `PPriv.py`, `PPub.py`.
- **Protocolos de Red:** UDP Custom, SlowDNS, BadVPN, OpenVPN.
- **Herramientas de Servidor:** Bloqueador de Torrent, optimizador BBR, SpeedTest, Firewall IPTables.
